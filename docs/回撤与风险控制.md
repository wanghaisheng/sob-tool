# 风险偏好与回撤率说明

本文说明本工具中的**回撤率**如何计算、**风险偏好**如何选用，以及二者如何与「最高/最低/收盘 − 均线」差值信号配合使用。

---

## 1. 回撤率是什么

### 1.1 定义

在一段观察期内，先记录**阶段峰值（Peak）**——通常取已加载 K 线内的**滚动最高价**（可按「全部 / 近 20 / 60 / 120 日」窗口配置）。

**收盘回撤率：**

\[
\text{回撤\%} = \frac{\text{Peak} - \text{当日收盘价}}{\text{Peak}} \times 100\%
\]

含义：从阶段最高点回落到当前收盘，已经吐出了多少比例的涨幅。

### 1.2 相关辅助指标

| 指标 | 含义 | 用途 |
|------|------|------|
| **阶段峰值 Peak** | 窗口内运行最高价 | 回撤计算的分母基准 |
| **回撤基数** | 窗口内 \(\max(\text{最高价} - \text{均线})\) | 衡量「相对均线的最大溢价」 |
| **溢价回撤%** | 相对回撤基数的回落程度 | 辅助判断情绪从高潮回落的幅度 |
| **最高 − MA / 收盘 − MA** | 价与均线的绝对差值 | 顶部：正差值由大变小；底部：负差值由小（更负）变大（收敛） |

回撤率回答的是「相对高点亏了多少」；差值回答的是「相对均线偏得有多夸张」。两者一起用，比单看涨跌幅更稳。

## 2. 风险偏好档位

工具中可配置下列偏好（单位：回撤% 阈值）：

| 档位 | 阈值 | 适合谁 | 典型行为 |
|------|------|--------|----------|
| **保守 5%** | 5% | 厌恶波动、仓位本身较重、或标的弹性极大 | 回撤一触 5% 附近即开始减仓，几乎不扛深调 |
| **稳健 8%**（默认） | 8% | 多数普通用户、希望纪律明确 | 回撤接近/超过 8% 进入「预警」；配合绿盘与正乖离缩小执行减仓 |
| **平衡 12%** | 12% | 能接受中等波动、仍要避免腰斩级回撤 | 给趋势多留一点空间，但 12% 是明确警戒线 |
| **积极 15%** | 15% | 对单票波动容忍更高、总仓位可控 | 中段震荡不易被洗出，但需更严格的总仓位上限 |
| **进取 20%** | 20% | 高弹性标的、小仓试错、或经验较多 | 只有回撤接近两成才强制降仓；深亏风险更大 |

### 2.1 状态标签（工具内）

相对你所选阈值 \(R\)：

| 状态 | 条件（约） | 含义 |
|------|------------|------|
| **安全** | 回撤 \(< 0.5R\) | 相对峰值回落不大，可按原信号正常操作 |
| **关注** | \(0.5R \le\) 回撤 \(< R\) | 接近阈值，提高警惕，准备分批减仓 |
| **预警** | \(R \le\) 回撤 \(< 1.5R\) | 已触偏好线，建议减仓/暂停加仓 |
| **超限** | 回撤 \(\ge 1.5R\) | 明显超出偏好，优先风控，反弹只宜小仓试探 |

示例：选 **稳健 8%** 时，约 4% 以下偏安全，8% 起预警，约 12% 起超限。

## 3. 如何选择适合自己的档位

### 3.1 先问三件事

1. **单票仓位有多重？**  
   - 单票 30% 以上 → 更宜 5%～8%  
   - 单票 10% 以内 → 可考虑 12%～15%

2. **标的弹性有多大？**  
   - 科创、题材、高换手 → 同一回撤% 来得更快，阈值宜偏严（5%～8%）  
   - 大盘蓝筹、低波动 → 可略放宽（8%～12%）

3. **你能否执行「减仓」而不是「扛住」？**  
   - 若历史上总是扛到腰斩才卖 → 先用更严的阈值强迫自己分批离场  
   - 若经常被洗出后踏空 → 可在总仓位可控前提下略放宽，但不要一次放到 20% 且重仓

### 3.2 经验对照（来自方法回测中的大致量级）

| 类型举例 | 从 Peak 到明显转弱的常见回撤 | 更匹配的偏好 |
|----------|------------------------------|--------------|
| 高弹性题材 / 科创 | 常 1～2 日打到 10%～18% | 5%～8% |
| 中等弹性成长 | 数日到 8%～15% | 8%～12% |
| 相对稳健蓝筹 | 回撤节奏较慢 | 8%～12%（仍不建议无纪律地扛 20%+） |

**原则：阈值是「你愿意主动执行减仓」的线，不是「扛到爆」的线。**

## 4. 回撤率与买卖信号如何配合

本方法**不是**只看回撤，而是：

```
差值规律（顶：正差缩小；底：负差收敛）
    + 当日红绿
    + 回撤是否触达你的偏好阈值
    → 综合给出减仓 / 观望 / 试探加仓
```

### 4.1 卖出 / 减仓侧

更可靠的组合往往是：

1. 阶段峰值出现（或最高 − MA 达极大正值）  
2. **收盘 − MA** 开始明显小于 **最高 − MA**（正溢价收缩）  
3. 收出**绿盘**（或大阴）  
4. **回撤% 接近或超过你的偏好阈值**

示例节奏（多票回测中反复出现）：

- Peak 日：即使收红，回撤已 5%～8%，且收盘弱于最高 → **预警减仓**  
- 次日大绿，回撤一次到 12%～18% → **确认离场**

### 4.2 加仓 / 试探侧

更可靠的组合往往是：

1. **最低 − MA / 收盘 − MA** 进入深负区后**开始收敛**（不再创新低）  
2. 收出**红盘**（最好有力度）  
3. 回撤虽可能仍大，但已从极值回升  

注意：

- 回撤仍 ≥ 你的阈值（甚至 1.5 倍）时，只宜**小仓试探**，不宜一次满仓。  
- 「超限区的红盘」≠「安全底部」，只表示下跌动能可能减弱。

### 4.3 仓位建议逻辑（摘要）

| 情形 | 建议倾向 |
|------|----------|
| 回撤 &lt; 0.5×阈值，且差值信号偏多 | 可按信号正常执行 |
| 回撤接近阈值，差值走弱 + 绿 | 分批减仓 |
| 回撤 ≥ 阈值 | 暂停加仓；已有仓位优先风控 |
| 回撤 ≥ 1.5×阈值 | 反弹只试探；禁止报复性加仓 |
| 深回撤后负差收敛 + 红 | 试探加仓，严格控制单票上限 |

## 5. 峰值统计窗口

回撤的「Peak」依赖窗口：

| 窗口 | 含义 | 适用 |
|------|------|------|
| **全部已加载 K 线** | 用当前数据段内的历史最高价 | 中期波段、从大顶算回撤 |
| **近 20 日** | 只看最近约一个月内高点 | 短线、不想被更早历史高点「绑架」 |
| **近 60 日** | 约一个季度 | 波段操作常用 |
| **近 120 日** | 约半年 | 中线持仓 |

同一天、同一收盘价，窗口不同，回撤% 会不同。  
**波段逃顶**多用「全部」或「近 60/120」；**短线**可看近 20 日，避免被半年前的天价抬高阈值。

---

## 6. 使用注意

1. **回撤阈值不是预测涨跌**，只约束「最多允许多深的浮亏后再动手」。  
2. **高弹性票**同样阈值会更频繁触发 → 单票仓位应更小。  
3. **美股等无涨跌停市场**单日即可跌破 8%～12%，更依赖事前设好阈值，而不是盘中临时做决定。  
4. 工具信号用于**纪律与复盘**，不保证收益；需结合自身资金、流动性与交易规则。  
5. 建议：先用历史数据回测自己常做的几只股票，再固定一档偏好长期执行，避免行情好时放宽、行情差时突然收紧导致紊乱。

---

## 7. 快速对照卡

| 我的情况 | 建议起点 |
|----------|----------|
| 新手 / 单票偏重 / 高波动票 | **5% 或 8%** |
| 普通用户、波段、总仓位分散 | **8% 或 12%** |
| 经验较多、单票很轻、能接受深波动 | **12%～15%**（仍建议设总回撤上限） |
| 把 20% 当默认且重仓 | **不推荐** |

| 信号组合 | 动作倾向 |
|----------|----------|
| 正差缩小 + 绿 + 回撤触线 | **减仓 / 卖出** |
| 负差收敛 + 红 + 回撤仍深 | **小仓试探加仓** |
| 回撤超限 + 无收敛 | **观望，不摊平** |
