# 冲高回落 · 回撤 · 二者比较

> 适用于「差值回撤信号」工具（sob-tool）。仅供学习研究，不构成投资建议。

---

## 1. 为什么要拆成两个指标

传统说法里「回撤」往往混在一起：

- 价格从最高点掉了多少；
- 相对均线的过热有没有消退；
- 我买了以后，浮盈从最高点吐了多少。

本工具把后两件分开：

| 名称 | 管什么 | 一句话 |
|------|--------|--------|
| **冲高回落程度** | 结构（相对均线） | 相对均线那次「冲得最远」的上冲，现在吐回去多少 |
| **回撤** | 账户路径（从入场价起） | 按窗起（或加仓日）收盘买入后，最大浮盈相对当前吐了多少 |

结构回答「热不热、冲力还在不在」；账户回撤回答「这笔（或这段）钱从赚得最多的时候掉了多少」。

---

## 2. 冲高回落

### 2.1 冲高峰值

在**时间焦点窗口**内（或加仓日起、自定义区间内），对每一天计算：

\[
\text{上冲}_t = \mathrm{High}_t - \mathrm{MA}_t
\]

\[
\text{冲高峰值} = \max_{t \in \text{窗口}} (\mathrm{High}_t - \mathrm{MA}_t)
\]

规则：

- 当日上冲 **大于** 此前峰值 → 峰值抬升为当日上冲（结构上「再创新高」）；
- 否则峰值不变。

这里的「新高」是 **相对均线的上冲新高**，不一定是股价创新高。

### 2.2 冲高回落程度

\[
\text{冲高回落\%} =
\begin{cases}
\dfrac{\text{冲高峰值} - (\mathrm{Close}_t - \mathrm{MA}_t)}{\text{冲高峰值}} \times 100
& \text{峰值} > 0 \\
0 & \text{否则}
\end{cases}
\]

- 分子：峰值上冲减去**当日结算差**（收盘−均线）；
- 结果为负时按 **0** 处理（结算仍高于历史最大上冲，视为尚未回落）。

### 2.3 读法

| 冲高回落% | 含义 |
|-----------|------|
| 接近 0% | 结算仍接近本窗最大上冲，冲力基本还在 |
| 中等 | 从极端上冲回落，结构在降温 |
| 很高 | 最大上冲已大幅吐回，乖离收缩甚至翻到均线下方 |

### 2.4 用途

- 判断是否「冲高后降温」（与正差从极值变小一致）；
- 路径力中「往下的力」的参考之一；
- 与风险阈值 R 比较时，可作结构风控标签（安全 / 关注 / 预警）。

### 2.5 不负责什么

- 不直接等于本金亏了百分之几；
- 不替代成本价、前高支撑等价格语言。

## 3. 回撤（账户路径）

### 3.1 入场约定

在时间焦点对应的 K 线子集上：

- **入场价** = 窗口**第一根**收盘价（有「加仓日 / 持仓窗」时，即从加仓日起）；
- **股数** = 默认 100 股（仅便于把比例显示成金额，逻辑与 1 股相同）。

### 3.2 计算

对窗内每一天 \(t\)：

\[
\text{浮盈}_t = (\mathrm{Close}_t - \text{入场价}) \times 100
\]

\[
\text{最大浮盈} = \max_{t} \text{浮盈}_t
\]

\[
\text{当前浮盈} = (\mathrm{Close}_{\text{最新}} - \text{入场价}) \times 100
\]

\[
\text{回撤金额} = \text{最大浮盈} - \text{当前浮盈}
\quad(\text{若最大浮盈}>0)
\]

\[
\text{回撤\%} = \dfrac{\text{回撤金额}}{\text{最大浮盈}} \times 100
\quad(\text{最大浮盈}>0)
\]

若整段从未浮盈（最大浮盈 ≤ 0）：

- 只展示相对成本的**浮亏金额**；
- **不**硬算「从峰值回撤%」（没有峰值浮盈可回）。

### 3.3 读法

| 情形 | 含义 |
|------|------|
| 回撤% 低 | 当前浮盈仍接近本段最好水平 |
| 回撤% 升 | 从赚得最多的时候往下掉，博反弹质量变差 |
| 从未浮盈 | 重点看浮亏金额与路径是否继续走弱，而非回撤% |

### 3.4 用途

- 建仓（或焦点窗起点）之后的加减清节奏；
- 与「是否绝对底部」无关：只对**入场点之后**的路径负责；
- 大级别深跌后的「疑似底」试多：用持仓窗 / 加仓日，避免被进场前的大坑峰值绑架。

### 3.5 不负责什么

- 不描述相对均线是否过热；
- 窗口起点一变，入场价与回撤数字会变（换焦点 = 换情景）。

## 4. 二者比较

| 维度 | 冲高回落 | 回撤 |
|------|----------|------|
| **坐标系** | 价格 − 均线 | 价格 − 入场价 |
| **峰值含义** | 最大上冲（结构） | 最大浮盈（账户） |
| **核心问题** | 过不过热、冲力吐了多少 | 赚过头又吐了多少钱 |
| **是否依赖入场** | 否（只依赖窗与均线） | 是（窗起或加仓日） |
| **与路径力** | 直接参与结构/往下的力 | 补充「持仓体感」 |
| **典型误读** | 当成亏了本金 xx% | 当成均线乖离回吐 |

### 4.1 为何不能互相替代

- **只看冲高回落**：可能结构已经冷却，但你若在半山腰买入，账户回撤仍很大（或仍浮亏）。
- **只看回撤**：可能浮盈回吐不多，但相对均线仍处极端上冲，存在「价还在、结构已过热」的风险。

稳妥用法：**结构管温度，回撤管这笔单的钱。**

### 4.2 和传统「价格回撤」的关系

| | 传统价格回撤 | 冲高回落 | 本工具「回撤」 |
|--|--------------|----------|----------------|
| 峰值 | 最高价 | max(最高−均线) | 最大浮盈（相对入场） |
| 当前 | 收盘价 | 结算差 | 当前浮盈 |
| 擅长 | 绝对空间、破前高 | 与 BIAS 一致的过热回吐 | 持仓路径风控 |

本工具仍可把「相对窗内最高价的跌幅」作对照，但不作为主信号。

### 4.3 时间焦点怎么影响两者

- 换 **短线 / 中线 / 长线 / 自定义区间**：两个指标的窗口一起变。
- **持仓窗（加仓日）**：冲高峰值从加仓日起累积；回撤入场价 = 加仓日收盘，最贴近真实持仓。
- 未填加仓日：回撤按**当前时间焦点的第一根收盘**做情景推演，不是券商里的真实成本。

## 5. 实操组合（简例）

**场景 A：大跌后疑似底，短线博反弹**

1. 设置加仓日 = 建仓日，焦点用短线或持仓窗。
2. 看 **回撤**：浮盈从高点吐多了 → 减仓 / 清仓优先。
3. 看 **冲高回落**：反弹中是否再次拉大上冲又快速回落 → 反弹质量差，少追。

**场景 B：趋势中持有，怕冲高回落**

1. 中线焦点看冲高峰值是否还在抬、冲高回落是否抬升。
2. 回撤看本段（或加仓后）利润保护是否到位。
3. 结构已大幅回落 + 账户回撤同步加大 → 减仓依据更强。

**场景 C：两指标背离**

- 冲高回落高、账户回撤低：可能入场偏晚或窗口起点偏高，结构已冷但账面还行 → 慎加仓。
- 冲高回落低、账户回撤高：结构冲力还在或已再创新高，但你买在更优价格之后的回吐 → 按风险偏好止盈/减仓，不必等结构转弱。

## 6. 命名对照（界面）

| 界面文案 | 含义 |
|----------|------|
| 冲高峰值 | max(最高−均线) |
| 冲高回落% / 冲高回落程度 | (峰值−结算差)/峰值 |
| 回撤 | 最大浮盈−当前浮盈（及可选%） |
| 曲线「冲高回落%」 | 与上同一结构序列 |

旧称「回撤基数 / 差额回撤」已弃用，避免与账户「回撤」混淆。

---

## 7. 一句话总结

- **冲高回落**：这段里相对均线冲得最远的那一截，收盘还留住多少。  
- **回撤**：从窗起（或加仓日）买入算起，利润从最好的时候掉了多少。  
- **一起用**：一个看结构温度，一个看持仓钱袋；不要用同一个数字同时解释两件事。
