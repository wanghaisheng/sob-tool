# 差值 · 红绿 · 回撤 交易方法论文档

**版本：** 1.0  
**适用工具：** `stock_signal_analyzer.html`  
**配套说明：** `差值指标与买卖判断说明.md`、`风险偏好与回撤率说明.md`、`README.md`

## 摘要

本方法是一套面向普通交易者的**纪律型波段框架**，核心不是预测涨跌，而是用可计算的三类信息约束仓位：

1. **差值（乖离）**：价格相对均线偏离的大小与**方向变化**  
2. **红绿**：当日收阳 / 收阴，作为转折确认的辅助  
3. **回撤**：相对阶段峰值的回落幅度，与个人风险偏好阈值比较  

> **顶部：** 正差值由大变小 + 常配合收绿 + 回撤触及偏好 → 减仓 / 卖出  
> **底部：** 负差值由深变收敛 + 常配合收红 + 回撤自极值回升 → 小仓试探加仓  

方法强调：**只在极值区附近动手，中间多数时间观望或持有既有纪律仓位。**

## 1. 问题背景与设计目标

### 1.1 普通交易者常见困境

- 涨的时候舍不得卖，等均线死叉时回撤已深  
- 跌的时候急于抄底或摊平，负乖离仍在扩大  
- 缺乏与自身风险承受力绑定的**量化离场线**  
- 多标的时难以每日统一扫描  

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 可计算 | 全部指标可由 OHLC + 均线得出，适合程序化 |
| 可解释 | 每个买卖建议能对应到差值、颜色、回撤中的具体条件 |
| 可配置 | 均线周期、回撤偏好、峰值窗口可由用户自选 |
| 可复盘 | 支持逐日记录与历史区间查询 |
| 跨品种适用 | 在 A 股高弹性票、指数及美股回测中规则结构保持一致（阈值需因地制宜） |

### 1.3 非目标

- 不承诺收益，不做点位预测  
- 不替代基本面、仓位总预算、交易规则（涨跌停、流动性）  
- 不作为高频或杠杆交易系统

## 2. 指标定义

### 2.1 均线 \(MA_n\)

\[
MA_n(t) = \frac{1}{n}\sum_{i=0}^{n-1} Close_{t-i}
\]

可选 \(n\)：20 日、30 日；或周线近似 25 / 50 / 100 / 150 日（对应约 5 / 10 / 20 / 30 周）。

### 2.2 差值（绝对乖离）

\[
\begin{aligned}
D_H(t) &= High_t - MA_n(t) \\
D_L(t) &= Low_t - MA_n(t) \\
D_C(t) &= Close_t - MA_n(t)
\end{aligned}
\]

| 符号 | 名称 | 作用 |
|------|------|------|
| \(D_H\) | 最高 − MA | 衡量上攻时相对均线的最大偏离 |
| \(D_L\) | 最低 − MA | 衡量杀跌时相对均线的最大偏离 |
| \(D_C\) | 收盘 − MA | 衡量收盘时真实站位（辅助核心） |

可选相对乖离：\(BIAS\% = (P - MA)/MA \times 100\%\)。工具主逻辑使用绝对差值以便同标的逐日比较。

### 2.3 红绿

\[
Color_t = \begin{cases}
\text{红} & Close_t \ge Close_{t-1} \\
\text{绿} & Close_t < Close_{t-1}
\end{cases}
\]

### 2.4 阶段峰值与回撤

峰值窗口 \(W\) 可为「全部已加载 K 线」或近 20 / 60 / 120 日：

\[
Peak_t = \max_{i \in [t-W+1,\, t]} High_i
\]

\[
DD\%_t = \frac{Peak_t - Close_t}{Peak_t} \times 100\%
\]

**回撤基数（溢价峰值）：**

\[
PremBase_t = \max_{i \in 窗口} (High_i - MA_n(i))
\]

**溢价回撤**可用于描述「相对均线最大溢价回落后还剩多少」，与 \(DD\%\) 互补。

### 2.5 风险偏好阈值 \(R\)

用户选择 \(R \in \{5\%, 8\%, 12\%, 15\%, 20\%\}\)。

| 状态 | 条件（约） |
|------|------------|
| 安全 | \(DD\% < 0.5R\) |
| 关注 | \(0.5R \le DD\% < R\) |
| 预警 | \(R \le DD\% < 1.5R\) |
| 超限 | \(DD\% \ge 1.5R\) |

## 3. 核心命题

### 命题 A — 顶部

当价格相对均线的**正偏离**达到阶段性极端后开始**收缩**，且价格行为确认（收盘跟不上最高、或收绿），上涨动能衰减概率上升；若同时 \(DD\%\) 触及个人阈值 \(R\)，应执行减仓而非等待更完美的技术死叉。

### 命题 B — 底部

当价格相对均线的**负偏离**达到阶段性极端后开始**收敛**（不再创新低），且出现收红确认，下跌动能衰减概率上升；允许**小仓试探**，但若 \(DD\%\) 仍远大于 \(R\)，禁止一次满仓。

### 命题 C — 中间区

正差未极端、负差未极端、或方向不明确时，**不主动开新仓**；已有仓位按回撤阈值与差值方向做持有 / 减仓管理。

## 4. 卖出规则（减仓 / 离场）

### 4.1 形式化条件

记近端窗口内 \(D_H\) 的极大值为 \(D_H^{\max}\)。卖出强度随满足条数增加：

| 编号 | 条件 | 说明 |
|------|------|------|
| S1 | \(D_H(t)\) 接近或等于 \(D_H^{\max}\) 后回落 | 正差见顶 |
| S2 | \(D_C(t) \ll D_H(t)\)（收盘明显弱于最高相对 MA） | 冲高回落 |
| S3 | \(D_H(t)\)、\(D_C(t)\) 较前几日缩小 | 正差收缩趋势 |
| S4 | \(Color_t =\) 绿（或次日绿） | 色能确认 |
| S5 | \(DD\%_t \ge R\) | 触及风险偏好 |

- **预警减仓：** 满足 S1 + S2（即使仍红）  
- **确认卖出：** 满足 S3 + S4，或 S4 + S5  
- **强制风控：** 满足 S5 且 S3（差值与回撤同时恶化）

### 4.2 操作建议（非指令）

1. Peak 日或正差极大日：先减 30%～50%（预警）  
2. 大绿且回撤过 \(R\)：再减至底仓或清仓  
3. 反抽不过前高、正差无法再放大：反抽减仓，不加回  

### 4.3 反模式（应避免）

- 只因「仍在均线上方」持有  
- Peak 日收红就否认顶部风险  
- 回撤已超 \(R\) 仍等均线死叉  

---

## 5. 买入规则（试探加仓）

### 5.1 形式化条件

记近端 \(D_L\) / \(D_C\) 的极负值为 \(D^{\min}\)。

| 编号 | 条件 | 说明 |
|------|------|------|
| B1 | \(D_L(t)\) 或 \(D_C(t)\) 接近 \(D^{\min}\) | 进入极负区 |
| B2 | 之后 \(D_C\) 抬升（负差收敛），低点不再显著创新低 | 抛压衰减 |
| B3 | \(Color_t =\) 红 | 色能确认 |
| B4 | \(DD\%\) 自极值回升（可仍 \(> R\)） | 回撤改善中 |

- **观察：** 仅有 B1  
- **准备：** B1 → B2  
- **试探加仓：** B2 + B3  
- **仓位上限：** 若 \(DD\% \ge R\)（尤其 \(\ge 1.5R\)），仅允许小仓，禁止满仓  

### 5.2 操作建议（非指令）

1. 深跌且负差仍扩大：空仓观望  
2. 负差收敛 + 红：加 1～2 成试探  
3. 次日绿：暂停加仓，等待再次收敛  
4. 试探仓再触发回撤止损（如再亏 \(R\)）则停手  

### 5.3 反模式（应避免）

- 负差很大就买（下跌中继）  
- 深跌第一根红满仓  
- 用摊平代替「收敛 + 红」条件

## 6. 综合决策表

| 差值状态 | 红绿 | 回撤 vs \(R\) | 倾向 |
|----------|------|---------------|------|
| 正差扩大 | 红 | 安全 | 持有，不追高 |
| 正差见顶缩小 | 红 | 关注 | 预警减仓 |
| 正差缩小 | 绿 | 预警/超限 | **卖出** |
| 负差加深 | 绿 | 任意 | **观望** |
| 负差收敛 | 绿 | 任意 | 观察，不加 |
| 负差收敛 | 红 | 仍深（\(\ge R\)） | **小仓试探** |
| 负差收敛 | 红 | 已明显收窄 | 分批加，仍控仓 |
| 混乱 / 矛盾 | — | 超限 | **优先风控** |

## 7. 参数选择方法论

### 7.1 均线

| 场景 | 建议 |
|------|------|
| 默认波段 | 20 日 |
| 减少毛刺 | 30 日或约 50 日（10 周近似） |
| 大级别 | 100 / 150 日，需足够历史 K 线 |

### 7.2 风险偏好 \(R\)

| 情况 | 起点 |
|------|------|
| 新手、单票重、高弹性 | 5%～8% |
| 普通分散波段 | 8%～12% |
| 单票很轻、经验多 | 12%～15% |
| 默认 20% 且重仓 | 不推荐 |

### 7.3 峰值窗口

| 窗口 | 用途 |
|------|------|
| 全部 / 近 120 日 | 中期波段逃大顶 |
| 近 60 日 | 常规波段 |
| 近 20 日 | 短线，避免被更早天价抬高回撤 |

### 7.4 标的差异

高弹性标的（题材、科创）极值更大、节奏更快 → **更严的 \(R\) + 更小的单票仓位**。  
阈值是「主动执行减仓的线」，不是「扛到爆的线」。

## 8. 历史验证方式（回测纪律）

对任一标的、任一段时期：

1. 拉取足够 K 线，计算 \(MA_n\)、\(D_H,D_L,D_C\)、Peak、\(DD\%\)、红绿  
2. 按第 4、5 节规则标记「预警减仓日 / 确认卖出日 / 试探加仓日」  
3. 对照后续 3～10 日价格路径，评估：  
   - 卖出后是否避免了更大回撤  
   - 加仓后是否出现可接受的反弹（而非立刻新低）  
4. **不**用单次结果证明方法永远有效；用于校准自己的 \(R\) 与执行习惯  

在 2026 年 6～7 月对多只高弹性 A 股及美股美光等样本的对照中，反复出现相似节奏：

- Peak 日或次日：正差收缩 + 绿 → 回撤快速到达 8%～18%  
- 深跌后：负差收敛 + 红 → 适合试探而非满仓  

（具体个股见历次回测记录；样本有限，外推需谨慎。）

## 9. 系统实现要点

### 9.1 数据

- 优先稳定的日线 OHLC 源（如东方财富等）  
- 多数据源可选，失败可回退  
- 本地缓存（如浏览器 SQLite）以支持批量与离线复盘  

### 9.2 计算流水线

```
输入代码 → 取 K 线 → 排序 → 算 MA
→ 算 DH/DL/DC、红绿
→ 按窗口算 Peak、DD%
→ 规则引擎输出信号与仓位建议文案
→ 展示 / 写入本地库 / SQL 查询
```

### 9.3 用户可配置项

- 数据源、K 线数量  
- 均线周期  
- 回撤偏好 \(R\)、峰值窗口  
- 观察列表（批量日更）

## 10. 完整每日流程（人工或工具）

```
1. 更新观察列表行情
2. 对每只股票读取：DH, DL, DC, 红绿, Peak, DD%, 状态
3. 对照综合决策表得出：减仓 / 观望 / 试探加仓
4. 检查总仓位与单票上限是否仍符合自己的风险预算
5. 记录理由（便于次日验证）
6. 中间区不交易；只在规则触发时动手
```

## 11. 局限与风险

1. **样本与过拟合：** 规则来自经验与有限回测，不同年份、风格市可能失效。  
2. **执行缺口：** 涨跌停、停牌、滑点、情绪导致无法按信号成交。  
3. **均线滞后：** 差值基于均线，极端单边市可能信号偏晚或反复。  
4. **绝对差值不可跨股直接比：** 应看自身极值与方向。  
5. **心理：** 方法不能消除恐惧与贪婪，只能提供事前约定的动作表。  

**本方法与工具不构成投资建议；市场有风险，决策与盈亏自负。**

## 12. 术语表

| 术语 | 含义 |
|------|------|
| 差值 / 乖离 | 价格与均线之差 |
| 正差缩小 | 上方偏离从大变小（顶区特征） |
| 负差收敛 | 下方偏离从极深收回（底区特征） |
| Peak | 阶段最高价 |
| 回撤% | (Peak−收盘)/Peak |
| 风险偏好 R | 用户设定的回撤容忍阈值 |
| 试探加仓 | 小比例建仓，等待验证 |
| 强制风控 | 回撤超限时优先减仓，不问故事 |

## 14. 结语

本方法的价值不在于「更准的预测」，而在于：

- 把「顶和底」从感觉变成**可检查的条件**；  
- 把「我能亏多少」写成**事前数字**；  
- 让多数交易日的默认动作变成**观望**，只在条件集合触发时行动。  

持续有效性取决于：参数是否匹配标的与仓位、执行是否稳定、以及是否定期用新样本复盘校准——而不是取决于某一段行情的幸运。
