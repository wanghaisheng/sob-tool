# 成交额异动过滤说明

**版本：** 1.0  
**定位：** 本方法的**增强模块**（非主信号）  
**主信号文档：** `差值回撤交易方法论文档.md`、`差值指标与买卖判断说明.md`  
**比较文档：** `与传统技术分析比较说明.md`

---

## 1. 为何需要成交额异动

主方法已经用：

- **差值转折**（正差缩小 / 负差收敛）  
- **红绿**  
- **回撤 vs 风险偏好**  

刻画顶和底。仍可能遇到：

| 问题 | 示例 |
|------|------|
| 假顶 | 正差略缩、收绿，但无量，只是洗盘 |
| 假底 | 负差略抬、收红，但无量或仅脉冲天量，次日再阴跌 |
| 真顶 | 高位放量长阴，正差塌陷 |
| 真底 | 深跌后温和放量收红，或巨量见底后次日缩量企稳 |

成交额（或换手率）异动用来回答：

> **这次差值转折，有没有资金真正参与？**

它是**过滤器 / 权重器**，不是第三套独立买卖系统，也**不替代**差值与回撤。

## 2. 基本定义

### 2.1 成交额

优先使用**成交金额**（元）。若仅有成交量（股/手），在股价平稳时可作近似，横截面比价时不如金额稳定。

### 2.2 基准：自身近期均值

对交易日 \(t\)：

\[
\bar{A}_{t,k} = \frac{1}{k}\sum_{i=1}^{k} Amount_{t-i}
\]

常用 \(k = 5\) 或 \(k = 10\)（不含当日，避免把异动日自己算进基准）。

### 2.3 异动倍数

\[
M_t = \frac{Amount_t}{\bar{A}_{t,k}}
\]

| 标记 | 建议阈值（可配置） | 含义 |
|------|--------------------|------|
| **放量** | \(M_t \ge 1.5\) 或 \(2.0\) | 明显大于近期 |
| **巨量** | \(M_t \ge 2.5\) 或 \(3.0\)，或创近 N 日额能新高 | 极端参与 |
| **缩量** | \(M_t \le 0.7\) 或 \(0.5\) | 明显清淡 |
| **平量** | 介于缩量与放量之间 | 无额外信息 |

### 2.4 可选：近 N 日分位

对高弹性票，固定 2 倍可能天天「放量」。更稳的做法：

- 计算当日额在近 20 / 60 日成交额中的分位数  
- **高分位**（如 ≥80%）→ 放量；**低分位**（如 ≤20%）→ 缩量  

工具实现时可二选一或同时给出。

### 2.5 换手率

若有流通换手率 \(T_t\)，可用同样方式相对近 k 日换手均值比较。  
换手更利于「大小市值之间」的 intuitively 对比；单标的序列上成交额通常已够用。

## 3. 与主信号的挂靠规则

### 3.1 总体原则

```
主信号成立（差值 + 红绿 + 回撤）
    → 再看量能
        → 同向异动：提高权重 / 允许执行
        → 反向或无量：降权 / 推迟 / 减小仓位
```

**禁止：** 仅因「放量」就买入或卖出，而不满足差值与红绿条件。

### 3.2 卖出侧（减仓 / 离场）过滤

| 主信号状态 | 量能 | 处理建议 |
|------------|------|----------|
| 正差缩小 + 绿 | **高位放量/巨量** | **加强卖出**：优先执行，甚至加大减仓比例 |
| 正差缩小 + 绿 | 平量 | 正常执行减仓 |
| 正差缩小 + 绿 | **缩量** | **降权**：可能洗盘；可减一部分，不必一次清空（除非回撤已超限） |
| 正差缩小 + 红（Peak 日预警） | 放量冲高回落 | 预警减仓权重提高 |
| 仅回撤超限 | 任意 | **回撤优先**：无论缩放量，先风控 |

**经典加强卖出：** 阶段高位 + 正差塌陷 + **放量长阴**。

### 3.3 买入侧（试探加仓）过滤

| 主信号状态 | 量能 | 处理建议 |
|------------|------|----------|
| 负差收敛 + 红 | **温和放量**（如 1.5～2.5 倍） | **加强试探**：允许按计划小仓买 |
| 负差收敛 + 红 | 缩量 | **降权**：反弹可能无力；仓位再减半或不买，等再确认 |
| 负差收敛 + 红 | **极端巨量**（如 ≥3 倍且一日吃掉近期额度） | **谨慎**：可能是反弹派发；仅极小仓或观察次日是否缩量企稳 |
| 负差仍加深 + 绿 | 巨量 | **不加**：恐慌盘，等收敛 |
| 主信号未满足 | 任意放量 | **不加不卖**（量能不单独开仓） |

**经典加强试探：** 深跌后负差收敛 + 红 + **温和放量**。  
**经典谨慎：** 深跌后无量地涨、或仅一根巨量阳线后量能无法持续。

### 3.4 中间区

差值未到极值、信号为观望时：

- 突然放量：只标记「关注」，不自动开仓  
- 用于人工看是否有事件驱动，仍回到主规则决策

## 4. 推荐默认参数（可改）

| 参数 | 默认建议 | 说明 |
|------|----------|------|
| 均值窗口 k | 5 或 10 | 5 更灵敏，10 更稳 |
| 放量倍数 | ≥ 1.8 | 可按标的分位校准 |
| 巨量倍数 | ≥ 2.5 | 或近 20 日额能最高 |
| 缩量倍数 | ≤ 0.6 | |
| 近 N 日新高/新低 | N = 20 | 辅助标记「天量/地量」 |

高弹性题材股可将「放量」改为近 20 日分位 ≥75%，避免倍数失效。

---

## 5. 与红绿、回撤的优先级

发生冲突时的优先级（从高到低）：

1. **回撤超限（≥1.5R）** → 先减仓/停止加仓，量能只影响减多少  
2. **主差值 + 红绿信号** → 决定方向（卖 / 试探买 / 观望）  
3. **成交额异动** → 决定执行力度（全做 / 半做 / 推迟）  

例：

- 回撤已超限 + 缩量绿：仍要卖，可分两笔，不必等放量。  
- 负差收敛 + 红 + 缩量：方向对，但力度弱 → 试探仓再削半。  
- 无主信号 + 巨量：不操作。

## 6. 实现要点（供工具扩展）

### 6.1 数据字段

日线需包含：`amount`（成交额）或 `volume` + 可估算均价；可选 `turnover`（换手率）。

### 6.2 输出标记示例

| 字段 | 示例值 |
|------|--------|
| 额能倍数 M | 2.3 |
| 量能标签 | 放量 / 巨量 / 缩量 / 平量 |
| 过滤结论 | 加强卖出 / 降权卖出 / 加强试探 / 降权试探 / 无影响 |

### 6.3 摘要文案示例

- 「正差缩小 + 绿 + 放量 → 卖出权重高」  
- 「负差收敛 + 红 + 缩量 → 仅允许更小试探仓」  
- 「主信号观望，忽略放量」  

### 6.4 注意

- 停牌后复牌、涨跌停封单日的成交额可能失真，宜单独标记。  
- 指数与个股阈值不同；观察列表批量时用**各标的自身**均值，不要用全市场统一额。

## 7. 简易检查清单（人工也可）

每日在主信号之后多问两句：

```
□ 今日成交额相对近5日（或10日）均值：放量 / 平量 / 缩量？
□ 若是「卖出类」主信号：放量是否加强离场？缩量是否改为分批？
□ 若是「试探买」主信号：温和放量是否执行？缩量/极端天量是否推迟或减半？
□ 若主信号为观望：是否做到「放量也不开仓」？
```

## 8. 与传统「量价理论」的关系

| 传统说法 | 在本过滤中的落点 |
|----------|------------------|
| 价涨量增 | 上升中可持有；本方法仍要防正差见顶 |
| 价涨量缩 | 顶区警惕；与「正差缩 + 缩量」一起看是否假突破 |
| 价跌量增 | 恐慌或出货；顶区放量阴 = 加强卖；底区需等收敛 |
| 价跌量缩 | 抛压减弱可能；需等负差收敛 + 红再试探 |
| 天量天价 | 近 N 日额能新高 + Peak → 预警减仓 |

本模块只借用量价中最易程序化、与主信号同向的部分，不展开完整经典量价体系。

---

## 9. 局限

1. 阈值需按标的校准，照搬 2 倍可能不适配。  
2. 事件市（财报、重组）额能失真，过滤可能误伤或误强化。  
3. 不能修复错误的主信号，只能调节执行力度。  
4. 无成交额数据的源上，本模块自动降级为「不启用过滤」。  

---

## 10. 总结

| 项目 | 说明 |
|------|------|
| 角色 | 主方法的确认与过滤层 |
| 输入 | 成交额（或换手）相对自身近 k 日 |
| 输出 | 放量/缩量标签 + 对买卖执行力度的加减权 |
| 不做什么 | 单独产生买卖点；不取代差值、红绿、回撤 |
| 与传统指标 | 不引入 MACD 等；量能是唯一推荐的增强维度 |

**一句话：**  
主信号决定「方向与是否允许动手」；成交额异动决定「这次动手用多大力、是否推迟」。
