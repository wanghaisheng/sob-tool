# 本方法与传统技术分析比较说明

**版本：** 1.0  
**相关文档：** `差值回撤交易方法论文档.md`、`差值指标与买卖判断说明.md`、`成交额异动过滤说明.md`

---

## 1. 比较目的

说明本套「差值 + 红绿 + 回撤」方法与常见传统技术分析（以 MACD、KDJ、RSI、均线金叉死叉、布林带等为代表）的**差异、重叠与取舍理由**，避免使用者再叠一套互相打架的指标系统。

**结论先行：**

> 本方法**不依赖** MACD / KDJ / RSI 等传统副图指标。  
> 主信号来自价格相对均线的偏离及其方向变化，辅以收盘红绿与回撤阈值。  
> 若需增强，优先考虑**成交额异动过滤**，而不是再引入动量类指标。

---

## 2. 传统技术分析常见做法（简述）

| 类型 | 代表 | 典型用法 |
|------|------|----------|
| 趋势均线 | MA5/10/20/60 金叉死叉、多头排列 | 金叉买、死叉卖 |
| 动量振荡 | MACD、KDJ、RSI、CCI | 金叉/超卖买，死叉/超买卖 |
| 通道波动 | 布林带、肯特纳 | 触及上轨卖、下轨买或突破跟踪 |
| 形态量价 | 头肩、双底、放量突破 | 形态完成 + 放量确认 |
| 多指标共振 | 若干指标同时发出同向信号 | 「共振」才开仓 |

传统体系的优点是资料多、软件自带；痛点是：**参数敏感、信号滞后或反复、多指标时解释成本高、与个人风险承受力无直接挂钩。**

---

## 3. 本方法在做什么

| 模块 | 内容 | 回答的问题 |
|------|------|------------|
| **差值（乖离）** | 最高/最低/收盘 − MA，看极值与方向变化 | 相对均线是过热还是过冷？转折了吗？ |
| **红绿** | 收阳 / 收阴 | 当天多空收盘谁占优？ |
| **回撤** | (峰值 − 收盘) / 峰值，对照个人偏好 R | 我已经浮亏多少？该不该强制减仓？ |
| **（扩展）成交额异动** | 放量/缩量相对自身近期 | 转折有没有资金参与？ |

不计算 DIF/DEA、K/D/J、RSI 曲线，也不以这类曲线的交叉为开平仓条件。

## 4. 逐项对照

### 4.1 与 MACD

| 维度 | MACD | 本方法 |
|------|------|--------|
| 信息来源 | 快慢 EMA 之差及其信号线 | 价格与单一（或选定）MA 的距离 |
| 买点常见表述 | DIF 上穿 DEA、柱由负转正 | 负差从极深收敛 + 收红 |
| 卖点常见表述 | DIF 下穿 DEA、柱由正转负 | 正差从极大缩小 + 收绿（+ 回撤触线） |
| 滞后性 | 双重平滑，剧烈行情中常偏晚 | 直接用当日高低收，对「冲高回落/探底回升」更敏感 |
| 参数 | 常用 12/26/9，改参信号大变 | 均线周期可选，但规则语义不变 |
| 与风险偏好 | 无直接接口 | 回撤% 与 R 显式绑定 |

**重叠：** 大级别顶底附近，MACD 死叉/金叉与「乖离收缩/收敛」有时同期出现。  
**取舍：** 既然后者已覆盖「动量由强转弱/由弱转强」的直觉，再叠加 MACD 易导致信号冲突（例如乖离已缩小但 MACD 未死叉而不敢卖）。

### 4.2 与 KDJ / RSI

| 维度 | KDJ / RSI | 本方法 |
|------|-----------|--------|
| 核心 | 一定窗口内的相对高低位置（0～100） | 相对均线的有符号距离 |
| 「超买超卖」 | RSI>70、<30 等固定阈值 | 看**自身近期**正差/负差是否创极值，而非全球统一 70/30 |
| 钝化 | 单边市中长期钝化 | 正差可持续扩大（持有），只在**缩小**时预警；负差同理 |
| 卖出 | 超买区死叉 | 正差缩小 + 绿 + 回撤 |
| 买入 | 超卖区金叉 | 负差收敛 + 红（小仓） |

**取舍：** 固定超买超卖线难以适配不同弹性个股；本方法用「自身极值 + 方向转折」替代。

### 4.3 与均线金叉死叉

| 维度 | 双均线交叉 | 本方法 |
|------|------------|--------|
| 卖出 | 短均线下穿长均线 | 价格相对**同一根**均线的正差收缩，可早于死叉 |
| 买入 | 短上穿长 | 负差收敛，可早于金叉 |
| 盘整 | 交叉频繁，假信号多 | 中间区默认观望，降低交易次数 |
| 回撤 | 死叉出现时回撤可能已大 | 用 R 提前约束，不必等交叉完成 |

本方法**仍使用均线**，但用法是「乖离」，不是「双线交叉」。

### 4.4 与布林带

| 维度 | 布林带 | 本方法 |
|------|--------|--------|
| 上轨 | 均线 + N 倍标准差 | 最高 − MA 的极大值（经验极值） |
| 下轨 | 均线 − N 倍标准差 | 最低 − MA 的极小值 |
| 卖 | 触及或跌破上轨后转弱 | 正差缩小 + 绿 |
| 买 | 触及下轨后转强 | 负差收敛 + 红 |

思想相近（都是「离中轴太远后的回归/转折」），本方法不引入标准差通道，减少参数（N、带宽）争议。

### 4.5 与「多指标共振」

传统：MACD + KDJ + RSI 同时金叉再买。  
问题：指标高度相关，共振不等于独立证据；且与仓位风险无关。

本方法的「共振」被重新定义为：

```
差值方向转折  ∧  红绿确认  ∧  （可选）量能异动  ∧  回撤状态允许
```

条件少、可解释、且含风控。

## 5. 本方法刻意保留与刻意放弃的

### 5.1 保留

| 保留项 | 理由 |
|--------|------|
| 均线 | 提供「中期成本/趋势中轴」参照 |
| 价格本身（OHLC） | 差值与红绿的唯一原料 |
| 回撤相对峰值 | 把风险偏好写成数字 |
| （扩展）成交额 | 确认资金是否参与转折 |

### 5.2 放弃

| 放弃项 | 理由 |
|--------|------|
| MACD / KDJ / RSI 等副图 | 与乖离信息重叠，增加冲突与参数负担 |
| 复杂形态命名为必选条件 | 主观、难程序化；需要时仅作人工备注 |
| 多周期指标堆叠为开仓前提 | 普通用户执行成本过高 |
| 「指标全空才能买、全多才能卖」 | 易导致永远不敢动手或永远满仓 |

## 6. 若有人已经在用传统指标，如何迁移

1. **先停掉副图开平仓条件**，只保留主图均线（一根即可，如 20 日）。  
2. 按本方法每日只看：\(D_H, D_L, D_C\)、红绿、\(DD\%\) vs \(R\)。  
3. 用历史 1～2 段行情对照：若过去是等 MACD 死叉才卖，看本方法是否更早给出「正差缩小 + 绿」。  
4. 需要增强时，加**成交额异动过滤**（见独立文档），而不是把 MACD 加回来。  
5. 总仓位、单票上限仍按资金管理执行，方法不替代仓位预算。

## 7. 一句话对照

| 传统常见说法 | 本方法对应说法 |
|--------------|----------------|
| MACD 死叉卖 | 正差从极大缩小 + 绿（+ 回撤触线） |
| MACD 金叉买 | 负差从极深收敛 + 红（小仓） |
| RSI 超买 | 自身 \(D_H\)/\(D_C\) 处在近期极大区 |
| RSI 超卖 | 自身 \(D_L\)/\(D_C\) 处在近期极负区 |
| 均线死叉 | 可不共用；用乖离收缩往往更早 |
| 指标共振 | 差值转折 + 颜色 + 量能 + 回撤允许 |
