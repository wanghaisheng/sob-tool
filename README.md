# sob-tool
When To sell or to buy   离场还是拿盆接



浏览器端股票分析工具：用**最高价 / 最低价 / 收盘价**与均线的差值，识别情绪极值并给出减仓、加仓建议。支持观察列表批量分析、多数据源、本地 SQLite 缓存与 SQL 查询。

**文件**：`stock_signal_analyzer.html`（单文件，用浏览器打开即可）

---

## 1. 这是什么？

一套面向 A 股（含科创板）的**纪律辅助工具**，核心思路：

| 场景 | 规则直觉 |
|------|----------|
| **顶部** | 最高价相对均线的**正差值**到极值后开始变小，且收盘价差值同步缩小 → 考虑减仓/卖出 |
| **底部** | 最低价相对均线的**负差值**到极值后开始收敛，且收盘价差值同步改善 → 考虑加仓/买入 |
| **中继** | 差值仍在扩大、未到极值 → 观望，不在半山腰乱动 |

收盘价与均线的差值作为**辅助确认**：更能反映资金最终认可的价格，减少仅看盘中最高/最低带来的噪声。

> **重要**：本工具用于减少追高杀跌、统一操作纪律，**不是**收益最大化或自动跟单系统。请结合自身风险承受能力使用。

## 2. 快速开始

1. 下载 `stock_signal_analyzer.html`
2. **推荐**用本地静态服务打开（减少接口 CORS 限制），例如：
   - VS Code 插件 **Live Server**
   - 或命令行：`npx serve .` 后在浏览器打开该页
3. 首次打开需能访问 CDN，以加载 **sql.js**（浏览器内 SQLite）
4. 在「单票查询」输入代码（如 `688596`）→ 点 **查询并分析**
5. 或把多只股票加入观察列表 → 点 **批量分析观察列表**

### 代码格式

- `688596`、`000001`、`600519`（6 位数字，自动识别沪/深）
- 也可写 `sh600519`、`sz000001`

## 3. 功能一览

### 3.1 全局配置

| 项 | 说明 |
|----|------|
| **数据源** | 东方财富（推荐）/ 腾讯财经 / 新浪财经 |
| **差值均线** | 20日、30日；或 5/10/20/30 周线的**交易日近似**（约 25/50/100/150 日） |
| **K线数量** | 120～1000，或「全部历史」（尽量多拉，受公开接口上限约束） |
| **缓存优先** | 优先用本地库 / 强制重新拉取 |
| **缓存有效期** | 不过期 / 6h～7 天；过期后自动重新拉取并写回 |

### 3.2 观察列表

- 支持一次输入多个代码（逗号、空格、换行）
- 保存在本地 SQLite，刷新不丢失
- **批量分析**：按当前均线与数据源，逐个计算并汇总信号
- 汇总表可点「详情」查看单票近 30 日明细

### 3.3 单票分析

- 计算所选均线的：最高−MA、最低−MA、**收盘−MA**
- 综合信号：建议减仓/卖出、加仓/买入、观望等
- 近 30 个交易日明细表，便于对照 K 线

### 3.4 本地 SQLite 库

浏览器内数据库（sql.js + IndexedDB 持久化），主要表：

| 表 | 内容 |
|----|------|
| `stocks` | 代码、市场、名称、更新时间 |
| `klines` | 日 K（开高低收、涨跌幅） |
| `analyses` | 每次分析的信号与差值 |
| `watchlist` | 观察列表 |

支持：**导出 / 导入** `.sqlite` 备份、**清空本地库**。

### 3.5 本地 SQL 查询模板

- 已缓存股票列表  
- 最近分析结果  
- **按日期区间查信号**（可填起止日期、可选代码）  
- 仅买入/加仓信号、仅卖出/减仓信号  
- 各股 K 线数量  
- **过期缓存列表**（相对当前「缓存有效期」）  
- 信号统计汇总  
- 同股多均线最近结果  
- 自定义 SQL

## 4. 方法说明（简要）

1. **顶部**：正乖离（尤其最高价−MA）达近期极值后回落，收盘−MA 同步走弱 → 减仓倾向更强。  
2. **底部**：负乖离（尤其最低价−MA）达极值后不再扩大、开始收敛，收盘−MA 改善 → 加仓倾向更强。  
3. 周线选项为日 K 上的周期近似，请配合足够 K 线数量或「全部历史」。  
4. 极值阈值与股价相关（实现上按价格比例自适应），不同标的波动差异大，信号仅供参考。

更完整的规则演进（含科创 50、上证、个股回看讨论）见你与助手的对话记录；本 README 只描述**当前工具行为**。

## 5. 使用建议（普通用户）

1. **先建立观察列表**（自己熟悉的、流动性尚的票），每日收盘后批量点一次即可。  
2. **中线**可试 10 周 / 20 周近似；**短线**用 20/30 日。选长均线时用「全部历史」或 500+ 根 K 线。  
3. 数据源优先**东方财富**；失败再换腾讯/新浪。  
4. 开启「优先用本地库」+ 合理「缓存有效期」（如 1 天），减少重复请求。  
5. 信号是**纪律提醒**：建议配合分批仓位，避免一次满仓/清仓；本工具不计算手续费、滑点与涨跌停约束。  
6. 定期用「按日期区间查信号」复盘自己的操作是否与规则一致。

## 6. 常见问题

**Q：提示 K 线数量不足？**  
A：实际拿到的根数少于当前均线所需。请选「全部历史」或更短均线（20/30 日），并确认代码正确。

**Q：接口失败 / CORS？**  
A：尽量用本地服务器打开页面；切换数据源；检查网络与代码是否为 6 位 A 股代码。

**Q：sql.js 加载失败？**  
A：需能访问 cdnjs 上的 sql.js。内网环境需自行改 CDN 或改为本地引入。

**Q：观察列表换电脑没了？**  
A：列表在浏览器本地。可「导出数据库」备份，在新环境「导入」。

**Q：能保证赚钱吗？**  
A：**不能**。震荡市可能假信号较多；工具不替代选股、仓位与风险管理。

## 7. 技术说明

- 纯前端：HTML + JS，无自建后端  
- K 线：公开行情接口（东方财富 / 腾讯 / 新浪）  
- 数据库：sql.js（SQLite WASM），持久化到 IndexedDB  
- 信号为规则化启发式逻辑，阈值与「近端极值比较」相关，会随行情变化
