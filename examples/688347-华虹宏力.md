### 三、差值与红绿如何指导「离场 / 入手」

#### 1）第一轮减仓窗口：6/30～7/1

| 信号 | 现象 |
|------|------|
| 色 | 连续出现**绿** |
| 收盘−MA | 从大正值**明显缩小**（弱于最高−MA） |
| 回撤 | 7/1 收盘相对 Peak≈348，回撤约 **9%** |
| 操作含义 | 稳健 8%：已触发；平衡 12%：进入警戒 → **分批减仓**，不必等 −20% |

对应方法：**正差值到顶后变小 + 收绿确认**。

#### 2）假反抽、勿追：7/17～7/20

- 高−MA 再次抬高，但 Peak 仍是 6 月底高点量级，**未有效创新高**一段时间。  
- 7/20 收红、回撤收窄，更像反抽，不是新主升确认。  
- 若 7/1 已减仓，此处**不宜一次性加回满仓**。

#### 3）第二轮更猛的冲顶与离场：7/21～7/23

| 日期 | 关键点 |
|------|--------|
| 7/21 红 | 涨停级，Peak 抬到约 398；情绪极值，**不是**加仓理由，而是提高警惕 |
| 7/22 绿 | 盘中高约 **413**，收 390 → 回撤约 **5.6%**；**最高−MA 达极大、收盘−MA 明显小于最高−MA** |
| 7/23 绿 | 大跌，回撤约 **17%**；正乖离坍塌 |

- 风险偏好 **8%**：7/23 前就应已大幅减仓。  
- **12%～15%**：7/23 明确超限 → 清仓/底仓。  
- 教学结论：科创高波动下，**Peak 日收绿 + 次日长阴** 往往是「逃顶组合」，比死等均线死叉更快。

#### 4）入手侧（本样本末段）

- 7/23 后若继续下跌，需等 **最低−MA / 收盘−MA 进入深负区后开始收敛**，且最好再收红确认。  
- 当前样本在 7/23 以深跌收尾，**尚未出现完整「极值收敛 + 收红」的抄底完成形态**；只能记作「等待区」，不能记作买入完成。
