### 二、回撤怎么算（对应工具逻辑）

- **阶段峰值 Peak**：从区间第一天起，滚动更新的**最高价**（本样本最终 Peak = **88.66**，出现在 7/1）。  
- **收盘回撤%**  
  \[
  \text{回撤%} = \frac{\text{Peak} - \text{收盘}}{\text{Peak}} \times 100
  \]  
- **回撤基数（溢价口径）**：区间内 \(\max(\text{最高} - \text{MA})\)；再与当日 \((\text{收盘} - \text{MA})\) 比较，看「从最大正溢价回落了多少」。  
- 风险偏好示例：稳健 **8%**、平衡 **12%**、积极 **15%～20%**。

### 四、和「我们方法」的对照：何时离场、何时入手

**离场（减仓）节奏 — 用 7 月上旬举例**

1. **7/1**  
   - Peak = 88.66；收盘 83.66 → 回撤约 **5.6%**（仍可视为「刚破位」）。  
   - 最高−MA 处在区间最大正溢价附近；若次日收盘−MA、最高−MA **同时缩小**，即工具里的「正差值到顶后变小」。  

2. **7/2～7/3**  
   - 回撤升至约 **10%～13%**。  
   - 对 **8% 稳健**：已达/超过阈值 → 应已减仓。  
   - 对 **12% 平衡**：7/3 附近应执行减仓。  
   - 这不是「猜顶」，而是：**峰值锁定 + 回撤触发风险偏好 + 正乖离不再扩张**。

3. **7/10**  
   - 回撤约 **23%**，收盘弱、跌破均线。  
   - 即使更激进的 20% 阈值也已击穿 → 清仓/极低仓更符合纪律，而不是等更深跌再卖。

**入手（加仓）节奏 — 用 7 月下旬举例**

1. **7/17～7/20**  
   - 回撤 45%～53%，最低到约 39～40。  
   - **负乖离极大**，但单日尚可能继续挖坑 → 适合「关注/左侧试探」，不适合一次性重仓。  

2. **7/21**  
   - 涨停，收盘从极弱区抬升，回撤从约 53% 收至约 43%。  
   - 对应工具：**最低−MA / 收盘−MA 从极值区收敛** + 收红确认。  
   - 教学仓位：试探 2 成 → 若后续回撤不再创新高、收盘−MA 继续改善，再加到 5 成。  
   - **仍相对 Peak 回撤约 40%+**，说明这是「深跌后的反抽信号」，不是「已回到安全区」。

### 五、回撤基数与「程度」一句话总结

| 概念 | 本案例中的含义 | 数值直觉 |
|------|----------------|----------|
| 回撤峰值（价格） | 7/1 最高价 | **88.66** |
| 回撤%（收盘） | (Peak−收盘)/Peak | 7/2 约 10%；7/10 约 23%；7/20 约 **53%** |
| 溢价回撤基数 | max(最高−MA) 多出现在 7/1 前后 | 正溢价最大后开始缩小 = 逃顶辅助 |
| 风险偏好用法 | 8% / 12% / 20% 是**你的离场线**，不是预测线 | 先定承受力，再让回撤% 触发动作 |

### 六、对普通用户的操作启示（结合本票）

1. **冲顶段**：Peak 出现后 1～3 个交易日，回撤到自己阈值（如 8%～12%）且正乖离缩小 → **优先减仓**，不要等 −20% 才行动。  
2. **深跌段**：回撤 40%～50% 只说明「很痛」，**不等于立刻满仓**；等负乖离收敛 + 收盘转强（如 7/21）再分批。  
3. **科创高波动**：同一套 8%/12% 阈值，触发会比大盘蓝筹更频繁 → 仓位上限要更严。  
4. **工具用法**：用 HTML 工具加载 688596、「全部历史」或足够 K 线、均线选 20 日、回撤偏好选 8% 或 12%，对照上表验证「峰值 / 回撤% / 差值」是否一致。
